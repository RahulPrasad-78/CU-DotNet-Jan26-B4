ASP .NET CORE - an open source cross platform framework to create various types of web applications
1.MVC - with views
2.WEB API - for data operations without views

Features:
	- cross platform Web Server (Kestrel)
	- Request Pipeline- Middleware
	- modular support for services
	- Logging
	-DI(Dependency Injection)
	- Configuration Support (from diff files)
		launchSettings or appSettings
				  (connectionString)

MVC - Models Views Controllers
MVC is an architectural pattern to have separation of concerns
every component has separate responsibility
Controllers - will handle all requests
Models- will be handling data
Views - for presentations

In asp.net all applications starts as console app
we have program.cs and Main
This program defines the services used an the middleware

It will also create a Host(Web server) that will run the application using diff endpoints(urls)
By default we get a controller - HomeController
A controller is a class derived from Controller class naming convention - class NameController : Controller 
A controller class can have 1 or more Action methods
An Action Method returns ActionResult
that can be a view

In web application we work with some verbs
	GET POST PUT DELETE
by default an action method is for GET
if no attribute is otherwise provided
[HttpGet]

An action method returns a view with the same name as that of method name
